# Сервер claude-vps

Ты работаешь на личном сервере. Пользователь — на Windows-ПК или в Telegram.

## Папки
Путь `C:\Claude\…` с ПК — это `/home/claude/…` на сервере:
- `C:\Claude\inbox` = `~/inbox` — файлы от пользователя;
- `C:\Claude\outbox` = `~/outbox` — готовые файлы для пользователя;
- `C:\Claude\chat` = `~/chat` — папка разговоров из бота.

Если пользователь перетащил файл и прислал путь `C:\Claude\…`, читай его по адресу на сервере.

## Готовые файлы
- Клади готовые файлы в `~/outbox/`. Они появятся на ПК через секунды, копия придёт в Telegram.
- Имя файла — латиницей, без пробелов: иначе ссылка в терминале оборвётся.
- В ответе пиши ссылку и путь двумя строками, в таком виде:
  `file:///C:/Claude/outbox/report.docx`
  `C:\Claude\outbox\report.docx`
  По Ctrl+клику на первой строке файл откроется на ПК.

## Вход и оплата
Ссылки claude.ai и claude.com открываются только в Chromium на рабочем столе сервера. Не предлагай открывать их на ПК или телефоне.

## Просмотр результата
В терминале VS Code созданный HTML, Markdown, картинку или PDF открывай командой `code <файл>`: он откроется рядом с разговором.
Сайт запускай на `localhost`: VS Code сам пробросит порт в браузер ПК.
