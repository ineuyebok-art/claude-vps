# claude-vps

Одна команда ставит на VPS Claude Code, Telegram-бота и рабочий стол сервера. Дальше с телефона работает бот, а на Windows-ПК — ярлыки: терминал, VS Code, рабочий стол и папка `C:\Claude`, синхронизированная с сервером. Claude и браузер для входа работают только на сервере. Требования — в [docs/tz.md](docs/tz.md).

## Установка

Нужен VPS с Ubuntu 24.04 (4 vCPU, 8 ГБ RAM, 60 ГБ SSD) и токен бота от @BotFather. Войди на сервер по SSH и выполни:

```
curl -fsSL https://raw.githubusercontent.com/ineuyebok-art/claude-vps/main/install.sh | sudo bash
```

Установщик спросит токен и покажет IP, страну, код привязки бота и пароль sudo. Пароль сразу сохрани в менеджере паролей. Повторный запуск той же команды обновляет систему и не трогает данные и вход в Claude.

## Первые шаги

1. Отправь боту код привязки.
2. В боте: `/devices` → «Добавить ПК». Вставь строку в PowerShell на компьютере, затем вставь ключ боту и нажми «Подтвердить».
3. Открой ярлык «Claude — рабочий стол». В Chromium войди на claude.ai, Organization ID есть в Settings → Account. В терминале запусти `claude`: вход откроется в том же Chromium.
4. Второй Telegram-аккаунт: `/devices` → «Добавить Telegram».

После установки SSH пускает только ключи, подтверждённые в боте. Если бот недоступен, зайди через консоль в панели хостера: логин `claude` и пароль sudo.

## Команды на сервере

| Команда | Что делает |
|---|---|
| `cc [имя]` | Claude в задаче tmux |
| `claude-vps info` | IP, страна, версия, пароль рабочего стола; с `sudo` ещё пароль sudo |
| `sudo claude-vps token` | заменить токен бота |
| `sudo claude-vps update` | обновить из GitHub |

## Как устроено

| Папка | Что там |
|---|---|
| `install.sh` | установщик |
| `server/` | помощники, службы systemd, настройки рабочего стола |
| `bot/` | бот на Python, только стандартная библиотека |
| `windows/` | скрипты для ПК |
| `tests/` | тесты |

Пользователь `claude` запускает Claude Code, tmux и VNC и не имеет беспарольного sudo. Пользователь `ccbot` держит токен и действует от имени `claude` только через `as-claude`. Менять SSH-ключи может только помощник `keys`, а его вызывает бот после «Подтвердить».

Claude и браузер для входа работают на сервере, поэтому Anthropic видит IP сервера. Сервер закрывает только то, что идёт через него: заход на claude.ai с ПК или телефона, приложение Claude или клик по ссылке claude.ai там покажут настоящий адрес. Команды вроде `ss -tn` на сервере видят адрес подключённого ПК: подтверждай такие запросы Claude осознанно.

Известное ограничение: у `claude` есть sudo с паролем, поэтому пароль, введённый в терминале, где работает обманутый Claude, можно перехватить подменой `.bashrc`. При тревоге меняй токен из консоли хостера.

## Тесты

```
python3 -m unittest discover -s tests -t .   # бот и помощники
bash tests/shellcheck.sh                      # shell-скрипты
bash tests/vps/run.sh                         # полный прогон в чистой Ubuntu 24.04, нужны Docker и debootstrap
pwsh tests/ps-analyze.ps1                     # PowerShell
```

CI запускает первые два пункта и проверки на настоящей Windows.
