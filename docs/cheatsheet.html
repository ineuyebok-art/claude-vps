Шпаргалка Claude

Разговоры и фото — Telegram. Быстро спросить — терминал. Код и просмотр — VS Code. Вход и оплата — рабочий стол.

Отдать файл

TelegramФото, файл, Ctrl+V со скриншотом. Больше 20 МБ — ссылкой на Google Диск, Яндекс Диск или Dropbox (до 2 ГБ).
ПапкаКинуть в C:\Claude\inbox или перетащить оттуда в окно Claude.
Файл откуда угодноПКМ → «Отправить» → Claude, затем Ctrl+V в окне Claude.
СкриншотWin+Shift+S, затем Ctrl+Alt+V в окне Claude.
VS CodeПеретащить файл в его проводник.

Получить файл

На ПКФайл уже лежит в C:\Claude\outbox. Ctrl+клик по ссылке file:///C:/Claude/outbox/… в ответе открывает его.
В TelegramКопия приходит сама. Больше 50 МБ — только путь.
ПросмотрВ VS Code Claude открывает HTML, Markdown, картинки и PDF рядом с разговором командой code файл.

Важно

Ссылки claude.aiОткрывай только на рабочем столе сервера. Клик на ПК или телефоне покажет Anthropic твой настоящий IP.
УдалениеФайл, удалённый в C:\Claude, удаляется и на сервере.
РасширенияVS Code и расширения — только из Microsoft Marketplace.
Тревога от ботаУдали устройство в /devices, выйди из claude.ai во всех сеансах, смени токен из консоли хостера: sudo claude-vps token.
